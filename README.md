# Rossmann Store Sales Prediction

## Project Overview
This project predicts store sales and customer numbers using Machine Learning.

The dashboard is built using Streamlit and allows users to:
- Upload CSV files
- Predict future sales
- Predict customer counts
- Visualize predictions using charts
- Download prediction results as CSV

---

## Features
- Interactive Dashboard
- CSV Upload Support
- Sales Prediction
- Customer Prediction
- Download Predictions
- Visualization Charts
